# Card Flow Solo

Pet-проект для практики архитектуры, форм и работы с состоянием.

## Стек
- React 19 + TypeScript
- Redux Toolkit
- React Hook Form + Zod
- Radix UI + SASS
- Storybook, Vitest, Playwright
- i18next, React Router 7

## Что делал
- Настраивал архитектуру по FSD
- Писал типизированные формы с валидацией (RHF + Zod)
- Разрабатывал UI-компоненты в Storybook
- Покрывал код тестами
- Настраивал ESLint / Prettier / Stylelint

## Запуск
bun i
bun run dev
